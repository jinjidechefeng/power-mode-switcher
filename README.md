# PowerMode · Windows 电源模式一键切换

一个单文件 `.bat` 小工具：显示当前电源状态，一键在「极致续航」和「极致性能」两种模式间切换，并可完整还原原始设置。

不需要安装任何东西，双击即可运行（会申请管理员权限）。

```
  ============================================================
                        电源模式切换工具  v1.0
  ============================================================

  时间     : 2026-10-29 17:35:44
  电源     : 已接通电源  100%
  电源计划 : 平衡
  屏幕     : 2560 x 1600 @ 60 Hz
  可用刷新 : 60 / 144 / 240 Hz
  息屏     : 接电源 20 分钟 / 电池 3 分钟
  CPU 上限 : 接电源 默认 / 电池 默认
  电池节能 : 电量 ≤ 50% 时开启
  屏幕色温 : 暖色（低蓝光）
  当前模式 : 未设置

  [1] 极致续航   30 秒息屏 + 电池节能 + 暖色屏幕 + 60Hz
  [2] 极致性能   最高刷新率 + CPU 满血 + 正常色温
  [3] 恢复原始设置
  [0] 退出
```

## 两种模式

### [1] 极致续航（笔记本不插电时用）

| 项目 | 动作 |
| --- | --- |
| 息屏 | 电池供电时改为 **30 秒**（接电源时不动） |
| 电池节能 | `ESBATTTHRESHOLD` 设为 100%，即电池供电时节能模式常开 |
| 电源模式 | 叠加切换到「最佳能效」 |
| CPU 上限 | 电池供电时 50% |
| 刷新率 | 降到当前分辨率下最接近 **60Hz** 的模式（没有 60 就取最低） |
| 屏幕 | 压低蓝通道，调成暖黄色 |

### [2] 极致性能（插电游戏/渲染用）

| 项目 | 动作 |
| --- | --- |
| 电源模式 | 叠加切换到「最佳性能」 |
| CPU | 上限与下限都锁 **100%**，保持最高频率 |
| 刷新率 | 跳到当前分辨率下的**最高刷新率** |
| 屏幕色温 | 恢复正常 |
| 息屏/节能 | 自动撤销续航模式改过的值 |

### [3] 恢复原始设置

切换任一模式前，脚本会把原始值备份到 `%LOCALAPPDATA%\PowerModeTool\backup.json`（含息屏时间、CPU 上下限、节能阈值、刷新率、原始色温曲线）。选 `[3]` 会把这些值全部写回，并切换回「平衡」电源模式。

## 使用方法

1. 把 `PowerMode.bat` 放到任意位置（桌面即可）。
2. 双击运行，在 UAC 弹窗里点「是」。
3. 按数字选择模式，`0` 退出。

只查看状态、不改设置：

```bat
PowerMode.bat --status
```

这个参数不需要管理员权限。

## 实现说明

* **电源设置**：通过 `powercfg /setdcvalueindex` 写入注册表
  `HKLM\SYSTEM\CurrentControlSet\Control\Power\User\PowerSchemes\<方案 GUID>\<子组>\<设置>`，
    读取时直接读注册表，避免解析本地化的 `powercfg /query` 输出。
* **刷新率**：`EnumDisplaySettings` 枚举当前分辨率下的所有模式，再用 `ChangeDisplaySettingsEx` 切换。
* **暖色屏幕**：调用 `SetDeviceGammaRamp` 压低蓝通道（约 62%），首次应用前会保存原始 ramp 以便还原。
* **显示/电源状态**：`System.Windows.Forms.PowerStatus` + Win32 显示 API。

## 已知限制

* 暖色用的是显卡 gamma 校色，而不是系统「夜间模式」——Windows 没有公开的命令行开关来切换夜间模式。**HDR 模式下可能不生效**。
* 刷新率和色温只作用于主显示器。
* 电源相关设置需要管理员权限；非管理员运行时会显示 `[注意] 写入失败`。
* 「最佳能效 / 最佳性能」依赖 Windows 10 1709+ 的电源模式叠加（`powercfg /overlaysetactive`），部分系统或 OEM 定制版本可能不支持，此时会提示跳过。
* CPU 下限锁 100%（极致性能模式）会让笔记本风扇变吵、温度变高，介意就用 `[3]` 还原。
